# SkillUp v29.1 — исправление запуска Telegram и демоданных

Это точечное обновление **основного фронтенда**, на базе ранее проверенного `SkillUp_v29_AUTH_CHECK_RAILWAY.zip`. Существующий API v0.2.1 и PostgreSQL не изменяются.

## Что исправлено

1. Удалён автоматический вызов `tg.requestFullscreen()`. `tg.expand()` остался — разворачивает Mini App в обычном режиме Fullsize; если Mini App уже находится в fullscreen, вызывается `exitFullscreen()` при наличии поддержки. Это не заменяет настройку Launch Mode в BotFather.
2. Добавлен `tg.disableVerticalSwipes()` при поддержке Telegram API v7.7+. Это предотвращает сворачивание Mini App при вертикальном свайпе по контенту. Свайпы по верхней панели Telegram и горизонтальные карточки остаются работоспособными.
3. **Новый локальный пользователь** без сохранённых данных видит пустые направления и финансовые суммы 0 ₽ вместо фиктивных целей/операций. Встроенные шесть демосценариев не удалены — загрузка доступна только после явного выбора в Профиле. Профиль теперь отмечен «Локально», а не «DEMO».
4. Удалены фиктивные уведомления при первом входе.
5. Оставлена диагностика Telegram по пяти нажатиям на логотип — `/api/v1/me` можно перепроверить.

## Важно о текущих данных

- **Этот пакет не очищает и не переименовывает существующие ключи localStorage.** Если на устройстве ранее сохранялся демопак или старые цели, они продолжат отображаться. Это намеренно: не стираем пользовательские данные.
- Даже при HTTP 200 от `/api/v1/me` пользовательские финансы, цели и чаты v29 пока **не синхронизируются** с PostgreSQL — это отдельный этап.
- `localStorage` пока привязан к браузеру и домену, а не к Telegram ID. Если переключить Telegram аккаунт в том же браузерном профиле, локальные записи могут быть общими. До внедрения защищённой облачной загрузки не используйте тесты со сменой аккаунта для приватных данных.
- Настоящий ИИ не подключён; статус «демо» в ИИ и в финансовых рекомендациях остаётся честным.

## Установка

1. Сделай резервную копию текущего GitHub-репозитория главного SkillUp.
2. Загрузи содержимое ZIP в **основной frontend-репозиторий**, не в `skillup-api`.
3. Дождись Deploy в Railway; в BotFather у Main App оставь **Fullsize**.
4. Полностью закрой Mini App и открой снова. Теперь не должно быть принудительного fullscreen. Попробуй вертикальный свайп внутри экрана (он не должен сворачивать Mini App), горизонтальные карточки и прокрутку.
5. Открой скрытую диагностику: 5 нажатий на логотип → `/me` должен показать **HTTP 200**.
6. Проверяй чистое начальное состояние на свежем профиле/устройстве без прежних localStorage данных — **не очищай** свой рабочий профиль для теста.
