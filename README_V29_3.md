# SkillUp v29.3 — один ИИ-помощник, одна общая история

Основа — рабочая v29.2.1 с PostgreSQL-синхронизацией финансов и развития и iOS-экспортом локальной копии. Четыре вкладки, заголовки, диаграммы, карточки, Fullsize и swipe behavior не менялись.

## Как установить

1. Сначала обновить **существующий** `skillup-api` архивом `SkillUp_v29_3_API.zip`, добавить секрет `ANTHROPIC_API_KEY` в Railway и проверить `/health`.
2. Сохранить резервную копию из Профиля (для iPhone: системное «Поделиться» → «Сохранить в Файлы» или запасной вариант копирования).
3. Распаковать этот архив в **корень репозитория основного SkillUp** (Nginx frontend); файл `skillup-ai.js` должен быть рядом с `index.html` и `skillup-cloud.js`.
4. Deploy на Railway. Не менять BotFather URL: текущий адрес остаётся тем же.
5. Открыть Mini App через Telegram: во вкладке «ИИ» должен появиться единый чат. Сформулировать цель и попросить отчёт за 7 дней; закрыть приложение, открыть заново и проверить историю. Затем зайти тем же Telegram-аккаунтом на втором устройстве и проверить переписку.

## Важно

- Данные фронтенда **не содержат** модельного API key. Он нужен только в сервисе API.
- Никакой fallback на притворные «ответы ИИ»: при проблеме с API выводится явная ошибка.
- Прежние локальные чаты и заметки v29 не удаляются. Кнопка «Перенести старую переписку» появляется, только когда найдены старые сообщения; нужно подтвердить перенос. Демо-ответы при переносе помечаются как шаблонные, чтобы не выдавать их за настоящий ИИ.
- Заметки остаются в локальном резервном экспорте; новый облачный редактор заметок добавим позже.
- На этом этапе ИИ может **предлагать** этапы и расписание текстом, но не может без подтверждения записывать их в Развитие.
- Базовая синхронизация целей и финансов продолжает работать отдельно, через существующий `skillup-cloud.js`.
