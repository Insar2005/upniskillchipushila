# SkillUp v29.5 frontend — ИИ как настоящий чат

Установка: загрузить `index.html`, `skillup-ai.js`, `skillup-cloud.js`, `Dockerfile`, `nginx.conf` и `railway.toml` в **существующий** GitHub-репозиторий основного SkillUp; Railway должен собрать новый образ из актуального коммита. Сначала обновить существующий API до v0.3.2-chat-media (см. общую инструкцию).

Изменения: только один ИИ-чат без технических блоков; чат сам прокручивается, поле ввода закреплено; «+» для фото/PDF, «🎙» для голосовых, история и OCR через тот же SkillUp API. В Финансах убрана старая кнопка браузерного диктофона — ручные кнопки дохода/расхода остались.

В Профиле появится валюта по умолчанию для сообщений без указания валюты. Текущий финансовый обзор **не складывает разные валюты**: RUB остаётся отдельным балансом, другие валюты отображаются отдельно. Для единого пересчитанного баланса необходим последующий этап с курсами обмена.

Старый `skillup_ai_workspace_v29` не удаляется. Перенос старых записей доступен в меню ••• внутри чата после подтверждения пользователя.
