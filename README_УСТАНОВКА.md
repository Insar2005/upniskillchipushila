# SkillUp v29.12 — фронтенд: Chat Layout + PWA Login

## Что исправлено

- Возвращены общая шапка SkillUp и заголовок «ИИ-помощник» во вкладке ИИ.
- Убрана пустая область над чатом, сохранились заблокированный фон и прокрутка только сообщений.
- Добавлен экран «Войти через Telegram» в Safari/PWA, когда подписанное Mini App initData отсутствует.
- При наличии PWA-сессии загрузка ИИ и облачных документов происходит через same-origin `/api/v1/*`.
- Внутри Telegram запросы по-прежнему используют проверенный `initData` и прежний адрес API.
- Nginx проксирует `/api/*` на существующий `skillup-api` без возврата HTML вместо JavaScript.

## Установка

**Не заменяйте обновлённый `index.html`, `skillup-ai.js` или `skillup-cloud.js`, если ваша текущая версия новее архивной v29.5.** Сравните файлы через Working Copy и перенесите изменения выборочно. Пакет использует фронтенд из предыдущего патча PWA, а тот — v29.5.

Сделайте резервный коммит основного фронтенда и убедитесь, что текущая синхронизация PostgreSQL работает. В `index.html` перенесите изменения CSS (`.top`, `.page-title`, `.pwa-*`), bootstrap входа в конце страницы и замену статических скриптов на условную загрузку. В `skillup-ai.js`, `skillup-cloud.js` перенесите выбор `API` по `initData`, разрешение cookie-сессии и `credentials:'same-origin'`. В `nginx.conf` добавьте `location ^~ /api/` с `proxy_pass`.

Для нового PWA с нуля положите также `manifest.webmanifest`, `icons/*` и COPY в Dockerfile (в этом архиве они уже есть).

## Проверка

1. Mini App через Telegram: все вкладки работают, HTTP 200 `/api/v1/me` по initData.
2. На вкладке ИИ видны общая шапка и заголовок, а фон при прокрутке сообщений не двигается.
3. В обычном Safari вне Telegram SkillUp показывает кнопку входа.
4. После настройки OIDC и установки backend-patch вход создаёт PWA cookie-сессию; `/api/v1/auth/me` возвращает пользователя.
5. В PWA (без Telegram) доходы, цели, история ИИ доступны через прокси на том же `telegram_id`.
6. Другой пользователь: авторизованная сессия не должна видеть чужие документы.
7. Проверьте вход и возврат из Telegram Login именно в iOS Standalone PWA: поведение перехода между приложениями может зависеть от iOS.

**Не запускайте вход в PWA, пока backend-patch не установлен.** Нажатие кнопки входа до этого вернёт 404.
